Política de Privacidade

Última atualização: junho de 2026

1. Introdução

Esta Política de Privacidade descreve como este software trata as informações dos usuários.

O software foi desenvolvido para funcionar sem necessidade de cadastro, login, identificação pessoal, criação de conta ou envio de dados pessoais para servidores externos do desenvolvedor.

Ao utilizar este software, o usuário declara estar ciente dos termos desta Política de Privacidade.

2. Coleta de informações

Este software não coleta, armazena, transmite, vende, compartilha ou processa dados pessoais dos usuários.

Nenhuma informação pessoal identificável é solicitada ou coletada, incluindo, mas não se limitando a:

  • nome;
  • e-mail;
  • telefone;
  • endereço;
  • CPF ou outros documentos;
  • localização;
  • contatos;
  • fotografias;
  • arquivos pessoais;
  • dados biométricos;
  • informações financeiras;
  • identificadores pessoais do dispositivo;
  • dados de prontuário;
  • qualquer informação destinada a identificar diretamente uma pessoa.

As informações eventualmente digitadas pelo usuário nos campos do software são utilizadas apenas localmente, no próprio dispositivo, para permitir o funcionamento da ferramenta. Esses dados não são enviados ao desenvolvedor, não são armazenados em servidores e não são compartilhados com terceiros.

3. Dados de saúde e informações sensíveis

Este software não solicita identificação de pacientes e não deve ser utilizado para registrar dados pessoais, dados de prontuário, nomes, documentos ou qualquer informação que permita identificar uma pessoa.

Caso o usuário insira parâmetros clínicos, valores, medidas, resultados ou informações relacionadas à saúde, esses dados serão processados apenas localmente no dispositivo, para fins de cálculo, consulta, referência ou apoio educacional.

O usuário é responsável por não inserir dados identificáveis de pacientes ou de terceiros.

4. Uso das informações

Como o software não coleta dados pessoais, não há uso de informações pessoais pelo desenvolvedor.

Os dados digitados pelo usuário, quando existirem, são utilizados exclusivamente para:

  • executar cálculos internos;
  • exibir resultados na tela;
  • permitir a interação com a ferramenta;
  • auxiliar em consulta, estudo, conferência ou referência.

Essas informações não são transmitidas, analisadas, monitoradas ou utilizadas para criação de perfil do usuário.

5. Armazenamento de dados

Este software não possui sistema próprio de armazenamento remoto de dados pessoais.

Não há banco de dados externo, conta de usuário, área de login ou servidor do desenvolvedor destinado a guardar informações pessoais.

Os dados inseridos durante o uso permanecem apenas na sessão local do aplicativo ou da página, conforme o funcionamento do dispositivo e do sistema operacional. O usuário pode limpar os campos, fechar o aplicativo ou reiniciar a ferramenta para remover as informações exibidas na tela.

6. Compartilhamento de dados

Este software não compartilha dados pessoais com terceiros.

Não há compartilhamento com:

  • anunciantes;
  • empresas parceiras;
  • plataformas de marketing;
  • serviços de análise comportamental;
  • redes sociais;
  • bancos de dados externos;
  • servidores próprios do desenvolvedor;
  • qualquer outro terceiro para fins comerciais.

Também não há venda, aluguel, cessão ou transferência de dados pessoais.

7. Publicidade

Este software não utiliza anúncios personalizados.

O software não coleta dados para publicidade, não cria perfil de usuário e não utiliza identificadores de publicidade para rastreamento.

Caso uma versão futura venha a utilizar anúncios, esta Política de Privacidade deverá ser atualizada antes da disponibilização dessa versão.

8. Cookies e tecnologias de rastreamento

Este software não utiliza cookies, pixels, beacons, scripts de rastreamento ou tecnologias semelhantes para monitorar o comportamento dos usuários.

Não há rastreamento de navegação, monitoramento de telas acessadas, criação de perfil comportamental ou coleta de estatísticas pessoais de uso pelo desenvolvedor.

9. Analytics e relatórios de uso

Este software não utiliza ferramentas de analytics, métricas de uso, rastreamento de eventos ou relatórios automáticos de comportamento do usuário.

O desenvolvedor não recebe informações sobre quais campos foram preenchidos, quais cálculos foram realizados, quanto tempo o usuário permaneceu no aplicativo ou quais telas foram acessadas.

Caso uma versão futura utilize ferramentas de diagnóstico, estatística ou relatório de falhas, esta Política de Privacidade deverá ser atualizada para informar claramente quais dados serão tratados.

10. Permissões do dispositivo

Este software não solicita permissões sensíveis do dispositivo para coleta de informações pessoais.

O software não acessa, para fins de coleta de dados pessoais:

  • câmera;
  • microfone;
  • localização;
  • contatos;
  • fotos;
  • vídeos;
  • arquivos pessoais;
  • mensagens;
  • chamadas;
  • sensores biométricos;
  • armazenamento externo com finalidade de coleta de dados.

Caso alguma permissão seja necessária para funcionamento técnico específico em versão futura, ela deverá ser usada apenas para a finalidade informada e esta Política de Privacidade deverá ser atualizada.

11. Serviços de terceiros

Este software não envia dados pessoais para serviços de terceiros controlados pelo desenvolvedor.

Entretanto, o uso do aplicativo por meio de lojas de aplicativos, sistemas operacionais ou dispositivos móveis pode envolver serviços externos independentes, como a própria loja de aplicativos, o sistema operacional ou mecanismos de segurança do dispositivo. Esses serviços seguem suas próprias políticas de privacidade, fora do controle direto do desenvolvedor deste software.

Esta Política de Privacidade refere-se exclusivamente ao funcionamento do software em si.

12. Segurança

Como este software não coleta, transmite ou armazena dados pessoais em servidores do desenvolvedor, o risco de exposição por transmissão externa é reduzido.

Ainda assim, a segurança das informações exibidas na tela depende também das práticas do próprio usuário, incluindo:

  • manter o dispositivo protegido por senha, biometria ou outro mecanismo de bloqueio;
  • evitar inserir dados pessoais identificáveis;
  • não compartilhar capturas de tela contendo informações sensíveis;
  • manter o sistema operacional atualizado;
  • utilizar apenas versões oficiais do software.

O desenvolvedor não se responsabiliza por exposição de informações causada por uso inadequado do dispositivo, compartilhamento voluntário de dados pelo usuário ou instalação de versões não oficiais.

13. Crianças e adolescentes

Este software não coleta intencionalmente informações de crianças, adolescentes ou quaisquer outros usuários.

O software não possui recursos de cadastro, mensagens, perfil público, interação social ou coleta de dados pessoais de menores de idade.

Caso o software seja utilizado por menores, recomenda-se supervisão de pais, responsáveis ou profissionais habilitados, conforme a natureza do conteúdo apresentado.

14. Direitos do usuário

Como o software não coleta nem armazena dados pessoais em servidores do desenvolvedor, não há banco de dados pessoal mantido pelo desenvolvedor para consulta, correção, portabilidade ou exclusão.

Ainda assim, o usuário pode entrar em contato para esclarecer dúvidas sobre privacidade, funcionamento do software ou tratamento de informações.

Quando aplicável, o usuário poderá solicitar informações sobre eventual tratamento de dados pessoais, conforme a legislação vigente.

15. Exclusão de dados

Este software não possui conta de usuário nem armazenamento remoto de dados pessoais.

Portanto, não há conta ou banco de dados pessoal mantido pelo desenvolvedor para exclusão.

Para remover informações digitadas durante o uso, o usuário pode limpar os campos, fechar o aplicativo ou apagar os dados locais do aplicativo nas configurações do dispositivo, quando aplicável.

16. Alterações desta Política de Privacidade

Esta Política de Privacidade poderá ser atualizada periodicamente para refletir mudanças no funcionamento do software, em exigências legais, em políticas de lojas de aplicativos ou em recursos eventualmente adicionados.

Caso futuras versões passem a coletar, armazenar, transmitir ou compartilhar qualquer tipo de dado pessoal, esta política deverá ser revisada antes da disponibilização da nova versão.

A versão mais recente desta Política de Privacidade deverá estar sempre disponível em local acessível ao usuário.

17. Aviso Legal e Isenção de Responsabilidade

Este software e todas as informações nele contidas são fornecidos exclusivamente com propósitos educacionais e de auxílio à referência médica. ESTE SISTEMA NÃO SUBSTITUI O JULGAMENTO CLÍNICO INDIVIDUAL, A ANAMNESE E O EXAME FÍSICO. As informações aqui apresentadas não devem ser utilizadas isoladamente para o diagnóstico, conduta ou tratamento de pacientes. A responsabilidade final por qualquer decisão clínica, prescrição ou intervenção é exclusiva do profissional de saúde assistente, devidamente habilitado.

Os desenvolvedores não garantem a precisão absoluta de todos os dados e isentam-se de responsabilidade por quaisquer danos diretos, indiretos, materiais ou morais que resultem do uso inadequado, interpretação equivocada ou confiança exclusiva nas informações deste sistema.

Pacientes e indivíduos leigos que utilizarem este software devem sempre buscar a orientação de um médico qualificado antes de tomar qualquer decisão sobre sua saúde.

18. Contato

Em caso de dúvidas sobre esta Política de Privacidade, privacidade de dados ou funcionamento do software, o usuário poderá entrar em contato pelo e-mail informado na página do desenvolvedor ou na loja de aplicativos.
